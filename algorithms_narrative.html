Initial Artifact

My initial app had a basic list to show events without sorting or filtering.

Enhancements Made

I added:

  • A quicksort algorithm to sort events by date in the View Events page.
  • A search method to filter events by title in the Search Events page.
  • Optimization to make sorting and searching faster.

Skills Demonstrated

These changes show my skills in:

  • Using algorithms like quicksort to sort data.
  • Handling data structures like lists efficiently.
  • Improving app performance.
