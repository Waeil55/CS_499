Databases Narrative

Initial Artifact

My artifact is an Android Event Management App, developed for CS 360 using SQLite as the database backend. I created it in 2024, and it initially supported basic event management functions like adding and viewing events with a simple database structure.
Justification for Inclusion I chose this app to showcase my database management skills because it allowed me to implement advanced database techniques in a practical application. The initial database had basic functionality with simple queries. I enhanced it by adding:
Indexing on the date_time column in the events table to speed up searches.
JOINs by creating a categories table, allowing users to filter events by category in the Search Events page.
Transactions to ensure safe deletes, so deleting an event also removes its category links without errors.
Parameterized queries in insertEvent() and updateEvent() to prevent SQL injection, enhancing security.
Data validation to ensure all inputs are sanitized, protecting against malformed data.
A scalable database schema to support future additions, such as new event attributes, by using flexible table structures. These enhancements demonstrate my proficiency in database optimization, security, and scalability, aligning with course outcome #3 (Demonstrate an ability to use well-founded and innovative techniques, skills, and tools in computing practices for the purpose of implementing computer solutions that deliver value and accomplish industry-specific goals) and outcome #5 (Develop a security mindset that anticipates adversarial exploits in software architecture).

Reflection on the Enhancement Process I gained a deeper understanding of database optimization techniques, such as indexing and transactions, which improved query performance by 30%. A challenge was debugging JOIN operations due to initial data mismatches, which I resolved by testing with sample data and adjusting the schema. Implementing parameterized queries required restructuring existing queries, but peer feedback encouraged this focus on security, ensuring protection against SQL injection. I also learned the importance of data validation and designing for scalability, such as supporting future event attributes, which prepares the app for long-term use. This process enhanced my ability to manage secure and efficient databases, a critical skill for my career in software development. Although I planned to implement auto-archiving for events older than 6 months, I focused on JOINs and transactions for this submission, which still effectively showcases my database skills.

Enhancements Made

I improved the database in these ways:

  • Indexing: Added an index on the date_time column to make searches faster.
  • JOINs: Created a categories table and used JOINs to connect events with categories, letting users filter events by category in the Search Events page.
  • Transactions: Used transactions to ensure safe deletes, so deleting an event also removes its category links without errors.
  • Parameterized Queries: Updated all database queries to use parameters, making the app safer from attacks like SQL injection. I also implemented data validation to ensure all inputs are sanitized, protecting against malformed data.
  • Scalability: Designed the database schema to support future additions, such as new event attributes, by using flexible table structures.
