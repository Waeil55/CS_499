A Showcase of My Android Event Management App and Technical Skills

Professional Self-Assessment

I am Waeil Mikhaeil, Bachelor’s Degree in Computer Science/Software Engineering Concentration. I built an Android Event Management App for CS 499, showcasing my expertise in:

  • Software Design and Engineering: Developed a user-friendly app with a bottom menu (Add Events, View Events, Search Events, Settings, Help pages), dark mode, and change password functionality (outcome #4).
  • Algorithms and Data Structures: Implemented quicksort and search methods to sort and filter events, enhancing performance (outcome #2).
  • Databases: Improved the database with indexing, JOINs, transactions, and parameterized queries for security and efficiency (outcome #3).

Throughout this project, I collaborated with peers during code reviews, incorporating their feedback to improve my app’s usability and functionality. I also honed my communication skills by presenting my code review video to both technical peers and non-technical stakeholders, ensuring clarity for diverse audiences.

This project aligns with all five Computer Science program outcomes:

  1. Solving problems (managing events).
  2. Using algorithms (quicksort, search).
  3. Managing databases (secure SQL).
  4. Designing software (user-friendly app).
  5. Working ethically (secure features).

My coursework and ePortfolio development have prepared me for a career in software development, equipping me with the skills to build impactful applications and communicate effectively in collaborative environments.
