Professional Self-Assessment

I am Waeil Mikhaeil, Bachlor's Degree in Computer Science/ Software Engineering Concentration. I built an Android Event Management App for CS 499, showcasing my expertise in:

  • Software Design and Engineering: Developed a user-friendly app with a bottom menu (Add Events, View Events, Search Events, Settings, Help pages), dark mode, and change password functionality (outcome #4).
  • Algorithms and Data Structures: Implemented quicksort and search methods to sort and filter events, enhancing performance (outcome #2).
  • Databases: Improved the database with indexing, JOINs, transactions, and parameterized queries for security and efficiency (outcome #3).

This project aligns with all five Computer Science program outcomes:

  1. Solving problems (managing events).
  2. Using algorithms (quicksort, search).
  3. Managing databases (secure SQL).
  4. Designing software (user-friendly app).
  5. Working ethically (secure features).

I am prepared for a career in software development, ready to build impactful applications.
