# Professional Self-Assessment

I am a Computer Science student passionate about building useful software. Through my CS 499 project, I enhanced an Android Event Management App, showing my skills in three areas:

- **Software Design and Engineering**: I built a user-friendly app with a bottom menu, dark mode, and features like Forgot Password. This shows I can design apps that people enjoy using (outcome #4).
- **Algorithms and Data Structures**: I added quicksort and search methods to sort and filter events, making the app faster and easier to use (outcome #2).
- **Databases**: I improved my database with indexing, JOINs, transactions, and parameterized queries, ensuring data is safe and fast to access (outcome #3).

These enhancements meet all five Computer Science program outcomes:
1. Solving problems with technology (my app solves event management needs).
2. Using algorithms and data structures (quicksort and search).
3. Managing databases (secure and efficient database).
4. Designing software (user-friendly app).
5. Working ethically (secure features like password hashing).
