Software Design and Engineering Narrative

Initial Artifact

My artifact is an Android Event Management App I created for a final project in CS 360 in 2024. It lets users manage events with a calendar, login system, and database, allowing them to add, view, and search events.

Justification for Inclusion: I chose this app for my ePortfolio because it demonstrates my software design and engineering skills in building a complete, user-friendly application. Initially, the app had basic pages to add and view events with a simple UI. I enhanced it by adding:

  • A bottom menu with Add Events, View Events, Search Events, Settings, and Help pages for easier navigation.
  • Dark mode for better usability in low-light settings.
  • Change password functionality to improve user account management.
  • A Forgot Password feature, including a new screen and database updates, to enhance user accessibility.
  • Material Design elements, such as an elevated calendar in the Add Event screen that auto-fills the date, improving the user experience.
  • Password hashing with BCrypt to enhance security.

These enhancements showcase my ability to design intuitive interfaces, implement secure features, and improve usability, aligning with course outcome #4 (Demonstrate an ability to use well-founded and innovative techniques, skills, and tools in computing practices for the purpose of implementing computer solutions that deliver value and accomplish industry-specific goals). They also meet outcome #5 (Develop a security mindset that anticipates adversarial exploits in software architecture) through the use of BCrypt for secure password storage.

Reflection on the Enhancement Process

While enhancing the app’s design, I learned how to implement Material Design principles, such as elevating the calendar for better user interaction, and how to integrate security features like BCrypt password hashing. A key challenge was ensuring the bottom menu worked seamlessly across all pages, which required debugging navigation issues in the activity transitions. Connecting the Forgot Password screen to the login page was also tricky, as I had to update the database schema to support password reset functionality, which I resolved by resetting the database for hashed passwords. I incorporated feedback from peers to improve the dark mode toggle, making it more intuitive by adding a settings switch. These enhancements improved the app’s usability, making it more accessible and visually appealing, and increased its security by protecting user data. I also learned the importance of user-centered design and secure coding practices, which will be valuable in my future career as a mobile app developer.

Course Outcome Alignment

This work meets outcome #4 (Software Design and Engineering) by showing I can build a complete, user-friendly app, and outcome #5 (Security) by implementing secure password hashing with BCrypt.
